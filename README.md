# Restaurant Website — HTML & CSS

A multi-page restaurant landing page built with plain **HTML and CSS** (no frameworks).

**Live demo:** https://html-css-website-49yf.vercel.app

## Pages

- **Home** (`index/index.html`) — hero section, services (master chefs, quality food, online order) and menu highlights
- **Contact** (`contact/contact.html`) — booking, general and personal contact details plus a query form

## Run locally

No build step — just open `index/index.html` in your browser.

## Structure

```
index/     Home page (index.html, main.css)
contact/   Contact page (contact.html, contact.css)
images/    Images and icons
```
